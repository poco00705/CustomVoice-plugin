# CustomVoice

BetterDiscord에서 기존 CustomVoice 백엔드의 음성 채널과 화면 공유를 이용하는 플러그인입니다. 현재 버전: **1.0.34**.

## 설치

[CustomVoice.plugin.js 다운로드](https://raw.githubusercontent.com/poco00705/CustomVoice-plugin/main/CustomVoice.plugin.js)를 BetterDiscord의 Plugins 폴더에 넣고 활성화하세요. 설정은 BetterDiscord → Plugins → CustomVoice에서 엽니다.

## 자동 업데이트

시작 시와 매 정시에 main의 최신 커밋을 확인합니다. 해당 커밋에 고정된 파일의 이름·버전을 검사하고, 설치된 파일보다 높은 버전일 때만 교체합니다. 교체 전 같은 폴더에 날짜가 붙은 .bak 백업을 만듭니다. BetterDiscord가 변경을 감지해 다시 로드합니다.

통화·방송 중에는 업데이트를 보류하고 다음 확인 시 재시도합니다. 로그인과 설정은 별도 BetterDiscord 데이터에 저장되어 유지됩니다. 네트워크 오류나 같거나 낮은 버전으로는 기존 파일을 교체하지 않습니다.

화면 공유의 시스템 소리 송출은 기본 켜짐입니다. 1.0.30에서 기존 설정도 최초 한 번 켜짐으로 전환합니다. 이후 공유 시작 창이나 방송 미리보기의 방송 설정에서 끌 수 있으며, 사용자가 끈 선택은 유지됩니다. 시스템 오디오는 선택한 앱에 한정되지 않을 수 있습니다.

## 새 버전 배포

개발 프로젝트에서 버전을 올리고 타입 검사·회귀 검사·빌드를 완료한 후 dist/CustomVoice.plugin.js를 이 저장소 main의 CustomVoice.plugin.js로 교체하세요. 이 저장소는 배포 파일만 포함하며 사용자 설정·세션·인증 정보는 업로드하지 않습니다.

## 1.0.32 서버 이전

기본 주소는 `https://mcv.modaweb.kr`입니다. 기존 `voice.222.121.56.92.sslip.io`와 `voice.125.132.41.195.sslip.io`를 쓰던 설정·기본 WebSocket 주소·저장 로그인 연결 정보를 업데이트 후 자동 전환합니다. 사용자 지정 서버 주소는 유지합니다. 서버 이전 과정에서 세션이 만료·삭제되었다면 재로그인이 필요할 수 있습니다.

## 1.0.33 고정 송출·단일 화질

선택한 해상도/FPS를 exact 캡처 제약과 해상도·프레임률 동시 유지 정책으로 적용합니다. simulcast·backup codec·dynacast를 사용하지 않으며 선택한 크기의 영상 인코딩 하나만 생성합니다. 미지원 환경이나 설정 불일치는 오류를 표시하고 자동으로 낮은 설정으로 대체하지 않습니다.

업데이트 후 화면 공유를 다시 시작하세요. 통화·방송 중에는 기존 자동 업데이트 정책에 따라 교체가 보류됩니다. 고정 정책을 지원하지 않는 Discord/Electron은 업데이트가 필요합니다. 브라우저의 자원 부족·정적 화면·전송 손실 등에 따른 실제 프레임 감소까지 막거나 실측 60FPS를 보장하는 기능은 아닙니다.

타입 검사·빌드, 단위/DOM/번들 검사 185개와 브라우저 스크립트 8개 통과. 별도 백엔드 인프라 검사 9개 생략. 실제 로컬 WebRTC 단일 인코딩과 1440p60↔720p30 설정·수신 해상도 변경을 검증했으며 실제 Discord 운영 방송 검증은 포함하지 않습니다.

## 1.0.34 원본 크기 캡처·프로필·동시 방송 시청

- 캡처 시작 시 원본 창에 1440p 크기를 강제하지 않습니다. 원본이 선택한 화질보다 작으면 원본 해상도를 유지하고, 더 크면 종횡비를 유지해 선택한 크기 안으로 줄입니다. 단일 인코딩과 FPS 유지 정책은 유지합니다.
- 신규 참가·재연결·상태 동기화 시 사용자명/아바타를 갱신합니다. 누락 프로필은 제한적으로 재시도하며 동시 조회와 오래된 응답을 처리합니다.
- 채널명·화질 표시와 컨트롤이 마우스 이탈 시 함께 숨습니다. 미니 화면/좁은 창에도 적용하며 키보드 조작과 열린 설정창은 유지합니다.
- 같은 음성 채널에서 여러 방송을 선택하여 격자·미니 화면·개별 팝업으로 동시에 시청할 수 있습니다. 각 방송의 소리·팝업·시청 종료를 따로 제어합니다.

타입 검사·빌드, 단위/DOM/번들 검사 196개와 브라우저 스크립트 9개 통과. 전용 백엔드 인프라 검사 9개는 생략했습니다. 실제 Discord/운영 SFU 송수신 검증은 포함하지 않으며 고정 정책이 실측 60FPS 전체를 보장하지는 않습니다.
